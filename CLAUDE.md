# dj-sorter — правила работы

## UI kit (обязательно для публичных страниц)
- Источник стилей: `docs/kit.css`, витрина и журнал: `docs/kit.html` (`/kit.html` на Pages).
- Новый UI-элемент на публичной странице (`index.html` и будущие):
  1. Ищем аналог в `kit.html`. Есть — используем его классы без изменений.
  2. Нет — добавляем стили в `kit.css` (в нужный раздел), демо и сниппет в `kit.html`, строку в «Журнал». Только после этого используем на странице.
- В `<style>` страницы только раскладка. Цвета, радиусы, тайминги — только токены `var(--…)`.
- Модификатор варианта: `.x--variant`; состояние: `.is-*`.
- `nerd_mode.html` — девтул, кит на него не распространяется.

## Деплой
- GitHub Pages из `main` `/docs`. Пуш через бандл на Mac (git-прокси песочницы блокирует репо).

## Версия
- `docs/version.js` генерирует git pre-commit хук (копия: `tools/pre-commit.sh` → положить в `.git/hooks/pre-commit`). Номер = число коммитов, показывается под лого на главной.
