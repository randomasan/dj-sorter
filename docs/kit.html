dj/sorter

UI kit

Единственный источник стилей публичных страниц. Тёмный интерфейс в духе Spotify: чёрно-серые поверхности, один зелёный акцент, пилюли, плотная жирная типографика. nerd_mode — девтул, кит на него не распространяется.

  1. Новый элемент → сначала ищем аналог здесь. Есть — используем его классы как есть.
  2. Нет аналога → сначала добавляем в кит: стили в kit.css (в нужный раздел), демо и сниппет сюда, строку в журнал. Только потом используем на странице.
  3. Никаких цветов, радиусов и таймингов «на месте». Только токены var(--…). В <style> страницы — только раскладка (позиции, сетки, отступы блоков).
  4. Вариант = модификатор (.btn--sm), состояние = .is-* (.is-active, .is-sorted).
  5. Акцент — один на экран. Зелёный только для главного действия и «живых» состояний.
  6. Логотип и название Spotify — только на кнопке входа (это требование их гайдлайнов для Connect-кнопок); свою айдентику под Spotify не маскируем.

Цвета

Токены из :root в kit.css. Значения ниже читаются из CSS вживую.

Движение

Шар

Визуал «Trails in Forms» (sabosugi, loader.js) в цветах кита. На главной во время загрузки — setActive(true) (сигналы ×3.5), в конце уменьшается в лого transform'ом без ресайза canvas.

mountLoader(el, { gui:false, follow:true, axes:true, params:{ backgroundColor:'#121212', lineColor:'#535353', dotColor:'#1ed760', dotLength:0.2 } })

Журнал

Каждое изменение кита — строкой сюда (свежие сверху).

2026-09-25Шар: слежение мягче — наклон до ~22° (MAX_TILT 0.38), изинг 1.6→12/с, полная резкость при скорости курсора от 3.5 px/мс.
2026-09-25Шар: без автовращения, фронтально. follow:true — наклон к курсору (до ~31°) только пока мышь двигается, стоп → возврат домой; изинг экспоненциальный, чем быстрее курсор, тем резче (rate 2.2→22/с), возврат мягкий (2.4/с). axes:true — отладочные оси XYZ.
2026-09-25Шар: сигнал = ровно --accent (#1ed760). Фикс loader.js: цвет сигнала без sRGB→linear конверсии + вычитание фона под additive-блендингом. Раньше уходил в кислотный (#19da37).
2026-09-25Шар: у сигналов хвост — dotLength 0.2 (было 0.01). Контур вернули к исходному (1px, #535353).
